# v0.93 官方優先、FinMind 缺漏補充

生效：2026-10-19；依使用者指示，取代 FinMind 全年度全市場逐股掃描策略。

## 來源順序

1. TWSE：上市行情、法人、融資券、借券、估值等，以端點實際支援欄位為準。
2. TPEx：上櫃同類資料，以端點實際支援欄位為準。
3. MOPS：月營收、財報及公告資訊，以實際可得期間與欄位為準。
4. FinMind：僅對官方來源驗證後的缺漏配對作補充，不為重複取得成功資料而逐股全掃。

## 抓取與驗證

- 使用官方支援的全市場按日、按月、按季批量入口；年度與三個月是任務範圍，不代表單一 API 可回傳全部年度資料。
- 沿用 0.93 已保存成功資料；先核對收據、檔案雜湊、內容日期及股票識別，再跳過成功單元。不得匯入 0.92 舊版資料。
- 缺漏配對至少記錄股票、來源、市場、資料集、日期/報告期間、欄位、缺漏原因及官方抓取證據。
- FinMind 補充先核對定義、單位、正負號、時間頻率與公告可得時間。保留 FinMind 原始來源標記，不覆寫官方原檔，不靜默混合欄位。
- 成功保存、基本格式通過、數值核對通過、PIT 通過及全市場完整率分開列示；未驗證不能標正確。來源拒絕或空回應不能直接判為零事件。
- 系統性錯誤隔離列報；個別失敗保留並繼續其他任務。保留成功資料、下載收據及斷點。
- 興櫃只保存、不納入上市上櫃分析。
