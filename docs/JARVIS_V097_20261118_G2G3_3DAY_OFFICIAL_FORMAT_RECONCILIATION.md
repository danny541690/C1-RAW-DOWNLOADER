## Current release protection and run policy
- Never add A/V2/Mapping/V3 numbers together. The only user-facing certified completion rate is G4 / 74,750 in `v097_V3_UNIFIED_MASTER_LATEST.json`.
- G2/G3 registered candidate counts are separate. A known source-wide web link and a correct CSV/HTML schema cannot certify historical source response SHA, official time-of-publication (PIT), security scope, or key semantics.
- Every mismatch receives a source_id, original SHA, date, dataset, source, error type, run ID, parser revision, evidence URI, retry count and terminal HOLD/EXCLUDED/RETRY decision.
- Existing properly checked files are not re-downloaded. ZIP members with unknown dataset stay pending; `.raw.receipt_*.json` is not numerical stock data; historical missing official pages are not treated as corruption.
- Workflow concurrency isolates V3 11 source shards from 7-source G2/G3 type/source lanes, and source-specific checkpoints are independent. GitHub cron is best-effort rather than a hard real-time SLA.
