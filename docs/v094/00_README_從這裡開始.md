## 先看這三件事
1. 本次是管理目錄、文件及治理規則0.94發布；正式下載程式仍為已存在的0.93版本。本次沒有遷移RAW、變更來源路徑、修改12條排程或宣稱分析管線全部上線。
2. 01_RAW及其他資料層只有原生Drive捷徑，連到0.93既有資料。捷徑不是備份，刪除或改寫目標會影響原資料。請勿在捷徑內整理原始資料。
3. 00_System/Policies的0.94總規則、三份SOP和Architecture的差異評估是新入口。Legacy_0.93與99_ARCHIVE內的舊文件是歷史證據，不代表目前狀態。

## 目錄用途
|路徑|放什麼|
|---|---|
|00_System|架構、總規則、三份SOP、知識與主控表歷史基線|
|00_INBOX|需求、待分類文件入口；既有暫存區以捷徑引用|
|01_RAW|指向0.93原始資料的捷徑，不建立第二套資料|
|02_STANDARD|標準事實資料入口，原資料以捷徑引用|
|03_FEATURES|指標入口與核准狀態，不把443項規格說成443項已計算|
|04_RESEARCH|股票、債券策略與回測證據；未通過品質不得升為正式訊號|
|05_CONTROL|設定、下載狀態、缺口、QA、版本、目錄及血緣清冊；即時資料以捷徑連原位|
|06_PORTFOLIO|個人部位、風險與交易紀錄入口；不自動下單|
|07_REPORTS|架構比較、整理驗收、歷史下載報告入口|
|99_ARCHIVE|0.93舊文件／測試索引；不冒充獨立備份|
|99_BACKUP|既有備份入口與還原規則，獨立備份狀態待查|
