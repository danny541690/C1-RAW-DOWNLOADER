`v093_repair_coordination` 使用 GitHub CAS 保存月份持有者，先成功領取者繼續，另一方進入 PAUSED_AT_MEETING，保存 meeting_month 與 survivor。重新執行也會保留暫停。持有者仍須取得既有 RAW_HISTORY_MONTH 月份鎖才能寫入 RAW；遇到下載工作占用或批次時間用完時，游標停在同月。

月份領取紀錄不是資料品質完成證明。持有者處理該月所有可執行單元；官方不提供、尚未發布、來源失敗與品質未解仍分開保留，不能因相遇或走訪完成而歸零。
