# 資料契約與研究門檻 R1
本文件為待落實的結構規格，不是本次建立新資料庫或已填妥的來源表。

每個dataset登錄：source、dataset_id、官方文件URL、scope、market、entity_type、frequency、calendar、earliest_available、latest_expected、publication_lag、retention_window、entitlement、rate_budget、schema_version、units、primary_key、time_fields、revision_policy、licence、required_by_strategy、coverage_status與證據日期。未知填UNKNOWN，官方窗口變動需新版本。七來源分別TWSE／TPEx行情與官方市場資料、MOPS公司公告財報、TDCC持股結構、TAIFEX期貨選擇權與法人資料、NDC景氣宏觀、FinMind補缺與國際資料；確切範圍按端點核對，不能用來源名稱推定全品項齊全。

控制資料至少包含dataset_registry、security_master_history、calendar、coverage_units、download_attempts、artifact_manifest、quality_results、release_manifest、strategy_registry與issue_log。市場資料存不可變檔案，控制索引可重建。manifest保存artifact_id、source、dataset、content_period、request_key、SHA256、bytes、retrieved_at、published_at、available_at、original_units、schema、parent_hash、quality_level、generation、release與storage_file_id。

股票研究最低依賴：歷史證券身分／上市下市、行情、公司行動、可得時間；財報策略另須公告與修訂的PIT。債券ETF研究最低依賴：歷史成分／身分或固定投資標的、價格、配息／總報酬、交易日、匯率及成本；個券再需票息、應計息、到期、提前贖回／違約與存續期。僅殖利率不能當債券持有報酬。

每一策略固定strategy_id、version、hypothesis、universe_as_of、signal_time、execution_time、required_datasets／fields、warmup、position/risk_rule、cost/slippage、benchmark、train/validation/test期間、OOS方式、input_release與reproducibility_digest。不在看到test結果後反覆調參再稱其樣本外。News保留原始公開證據、時間、關聯信心與訂正，未知歷史可得時間時不進PIT回測。

月／日報最少顯示：as_of、各來源latest_expected與latest_verified、應收／已存／基本驗／數值驗／PIT可用、未解錯誤與confirmed_exception、來源請求／成本、active release及最後成功run。母體未定就UNKNOWN；資料過期或QA未過不發布受影響策略訊號。
