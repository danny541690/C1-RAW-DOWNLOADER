# TDCC two-ended weekly history

Schedule 5 DESC owns official dates >= 2026-05-01, plus live OpenAPI snapshots. Schedule 5-1 ASC requests history from floor 2000-01-01 and owns official dates < 2026-05-01, ordered ascending. Current official weekly menu begins 2025-10-31; earlier dates are outside this query, not downloaded or certified absent. Fixed month partition avoids simultaneous RAW writes. Each worker has its own control root, status and per-date receipts. Existing successful snapshot metadata is inherited read-only by ASC; saved RAW is immutable and remote SHA readback stays enabled. Per-date retained successful receipts are loaded from each control root when available. Both use V4 validation, source-empty classification and bounded delayed retries. 16 tests passed before deployment. This does not add full-site publication/PDF/Excel archival or certify numeric/PIT correctness.
